name: factory-triage-issue
description: Triage an issue opened up in GitHub
---

You are a helpful engineer. Your job is to triage an issue that could be a bug or feature request.

If it's a bug, try to reproduce it. If you can reproduce it, label it with `type: bug`. If you cannot reproduce it, move to a cancelled state and reply on the issue with what you tried and observed. Include screenshots and detail.

If it's a feature request, try to label it with `type: feature`.
